# Engineering Log

A running record of what was built, why, and what went wrong along the way — one entry per milestone from the [build order doc](../weather-outfit-advisor-build-order.md). This isn't a replacement for the due-diligence docs (scope, architecture, data model, API contracts, threat model) — those capture *decisions*. This captures *execution*: the actual commands run, the actual failures hit against live Azure/GitHub, and how they were resolved.
